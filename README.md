# 云枢智测接口自动化测试项目

## 项目介绍
该项目是一套面向企业级 REST API 的自动化测试解决方案，基于 Python 构建。框架采用 Pytest 作为执行引擎，结合 YAML 数据驱动、Allure 报告可视化、分层日志记录等特性，解决了传统手工回归测试效率低、场景覆盖不全的痛点，实现了接口测试用例的可维护、可扩展与可追溯。

## 技术栈
Python + requests + pytest + yaml + allure + logging + jenkins + git + Charles


## 核心功能实现
1.  **接口自动化用例搭建**
    - 利用 `pytest + requests` 测试框架，编写了用户登录、商品下单、购物车加购等核心接口自动化用例；
    - 支持多场景用例执行（冒烟/回归/全量），通过 `pytest` 标记实现用例分组管理。

2.  **测试报告可视化**
    - 集成 Allure 生成可视化测试报告，直观展示用例通过率、缺陷分布、执行耗时等关键指标，便于快速定位问题；
    - 报告中包含请求详情、响应数据、断言结果，支持问题追溯。

3.  **完善的断言机制**
    - 构建多层级断言机制，包含 HTTP 状态码校验、业务响应码验证、响应数据字段检查等，确保测试结果全面可靠；
    - 封装通用断言工具类，支持自定义断言模板，减少重复代码。

4.  **数据驱动测试**
    - 采用 YAML 文件管理测试数据，实现测试逻辑与数据分离，提升用例可维护性；
    - 支持参数化执行、多组数据驱动，覆盖不同业务场景（如正常/异常参数、边界值等）。

5.  **分层日志记录**
    - 通过 `logging` 模块实现分层级日志记录（DEBUG/INFO/WARN/ERROR），自动捕获接口请求与响应详情；
    - 日志按日期自动归档，支持错误场景快速复现与问题排查。

6.  **功能测试用例设计**
    - 采用等价类划分、边界值分析、场景法等方法，设计了登录注册、商品搜索、购物车操作、用户下单等核心业务的功能测试用例；
    - 用例覆盖正常流程、异常场景、边界条件，保障功能完整性与稳定性。
